Lab Seminar 報告準備
報告分為兩種形式：
●
survey 類型：針對特定主題，分享 5 篇以上論文，實驗結果不用過多著墨，著重
介紹論文研究動機、方法框架、使用的資料集，並且總結 5 篇論文目前已完成的
議題探討
●
深入研讀類型：選定一篇長篇文章，仔細介紹研究動機、方法、資料集、實驗結果
(快要輪到自己的順序時，請先跟我確認採哪種形式的報告)
報告中需包含自己的看法，請著重對方法或實驗內容進行討論：
●
總結這篇論文的優點與缺點
●
對於這篇論文，有什麼問題想對作者提出的？
●
延續前一個問題，你自己會如何解決這些問題？

--- Page 12 ---
為方便管理，實驗室 OpenAI API 使用方式如下：
- Default project API key (也就是目前使用的 API key) 已經先行關閉，請使用各自 Project 的 API key。
- 我會為每位同學在 OpenAI Platform 建立各自 Project，請同學之後改使用 Project 建立 API key。
- 每個 Project 有限制每月上限，請同學在執行程式時要記得 handle 超過上限的狀況。
- 如需跑超過上限，請估算使用金額並跟我說一聲，我再幫同學調整上限至估算金額。
- 同學可以透過以下方式重新創建 API key：選擇自己帳號的 Project，到 API Keys 頁面生成。
