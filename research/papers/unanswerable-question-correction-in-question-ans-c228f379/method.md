# Method

## Paper claim

PKBQAC answers personal-KB questions when possible and otherwise corrects a question inconsistent with stored personal facts. A semantic-parsing QA stage produces candidate query graphs; if none matches the KB, a question-construction plus reinforcement-learning editing stage suggests an answerable question (pp. 1-2, 4-6).

## Builder interpretation

The key product decision is to help users repair a mistaken memory rather than simply return no answer.

## Unresolved question

How should a system present competing corrections without falsely asserting one memory is definitive?
